# MarketVault — PWA Lista de la Compra

Micro-app PWA independiente, ultraligera y local-first para el supermercado.

## Características
- **100% Offline (Local-First)**: Funciona en el sótano del supermercado sin cobertura utilizando IndexedDB.
- **Sin necesidad de cuenta**: Cualquiera puede instalarla y usarla inmediatamente.
- **Clasificación por pasillos**: Ordenación automática de productos por secciones del súper.
- **Sincronización opcional del hogar**: Vinculación mediante código de 6 caracteres con RecipeVault PRO.
- **Instalable (PWA)**: Icono esmeralda propio, pantalla completa y acceso instantáneo.

## Desarrollo
```bash
npm install
npm run dev    # Inicia en http://localhost:3001
npm run build  # Compilación de producción
```
